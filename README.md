# 💎 RAPIDOI
Researchers often need to download large numbers of scientific articles, but automated options are limited by publisher policies. 
This tool eases the downloading process and structures the resulting data into a convenient format suitable for subsequent analysis

# ⚖️ Features
- [x] Work with any article sources
- [x] Saving your current progress 
- [x] A completely standalone desktop utility
- [x] Allows you to bypass any DDoS protection
- [x] User-friendly and fast graphical user interface powered by Qt6

# 🧑‍🔬 System Requirements

> OS: Windows 10 or later, MacOS 11 (Big Sur) or later, Linux/BSD distribution with Qt6 support

# ⚙️ Installation

Go to the [releases](https://github.com/drxvmrz/rapidoi/releases) and download the latest version of installer. 
Then install it as usual on your operating system.
